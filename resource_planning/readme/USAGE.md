1. Under **Resource Planning ▸ Configuration ▸ Roles**, create the
   roles your resources fulfil (e.g. Technician, Supervisor).
2. Under **Configuration ▸ Resources**, declare which roles each
   resource can fulfil and its working calendar.
3. Under **Configuration ▸ Periods**, review the named day periods
   (Morning, Evening, Night, Day Off) shared by demand schedules and
   rotation matrices.
4. Create **Assignments** directly under Resources ▸ Assignments —
   pick the resource, the interval and optionally the role. Publish
   is refused on hard conflicts; eligibility issues show as warnings.

With `resource_planning_demand` installed, assignments can also be
linked to the service and requirement they fulfil.
