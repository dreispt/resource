Reusable **Rotation Plans** — a resource-code × cycle-day matrix of day
periods — applied to resources for a date range. Position support is
added by ``resource_planning_demand_rotation``.

Each matrix row is a **Crew** identity (A, B, C…) — the rotating team
identity in cyclic-roster literature. Equivalent terms across
industries:

- **Crew** — industrial/academic scheduling (4-crew systems, DuPont,
  Panama patterns).
- **Team** — SMB shift tools (Deputy, 7shifts).
- **Platoon** — US fire and EMS (Kelly 3-platoon schedule).
- **Watch** — naval and maritime rotations.
- **Turn / Turno** — Iberian and Latin-American escala.
- **Group / Squad** — police and security-guard rosters.

Usage
=====

Define a rotation matrix in Configuration ▸ Rotation Plans, then assign
it to a resource on the resource form's Rotation Plans section.
